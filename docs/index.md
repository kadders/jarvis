# Jarvis

Jarvis is an **LLM event API** (FastAPI) with optional **ASR**, **chat UI**, **Redis-backed idempotency**, and **Ollama** (default big tier **`llama3.1:8b`** on the pinned image) as the primary model path. Documentation is published from this site.
